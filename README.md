# 5G 通信时延研究阅读站

把现有研究说明、知识点、算法、报告、论文和3GPP协议放在同一个可携带的阅读目录中。

## 在另一台电脑使用

```bash
git clone https://github.com/ming0526288/5g-latency-research-reader.git
```

进入文件夹，双击 **`打开阅读站.html`** 或 `index.html`。Windows建议使用Edge或Chrome，macOS/Linux也可使用支持MathML和本地PDF的现代浏览器。

私有仓库需要使用有权限的GitHub账号克隆。阅读时无需联网、Python、Node.js、数据库或`npm install`。请完整复制/克隆文件夹，不能单独复制入口HTML。

## 阅读功能

- 六步阅读路线；知识点、算法、研究报告、CHG和TEST分类目录。
- 本地全文搜索：点击搜索框，或按`Ctrl K`/`/`。
- 行内/独立公式排版，分数、上下标、求和等使用本地KaTeX字体；协议OMML转换为MathML。
- 原文图片及测量区间示意图。
- 文档相互跳转、右侧标题目录、上一课/下一课。
- 文献PDF页序定位；支持手动选页和独立打开PDF。
- 协议条款、分册、IE关键词定位；支持打开原始Word文件。
- 浏览器本地书签、阅读进度、深浅主题；它们不随Git同步。

## 原文与定位边界

论文与教材使用**本地PDF从1开始的页序**，它可能与印刷页码不同。明确识别出文献和有效页码的引用才建立页码链接；不能可靠识别的引用保留原文，不猜页码。PDF内更精确的段落或公式位置需要在目标页查看。

协议网页是**本地转换阅读页**，不是官方发布网页或官方PDF。保留条款与分册目录；精确排版、合并单元格、原始矢量图及复杂公式应以随仓库保存的Word原文为准。Word里的部分WMF/EMF原图不能直接在浏览器显示，页面会提示打开Word核对。当前库是用户提供版本，未据此声称独立核实了官网最高版本。

历史报告和计划保持各自版本身份。“当前”“下一步”可能是文件写作当时的状态；研究最新接续请从首页最后一步进入。文档网页化没有重新执行实验或重新认证旧结论。代码、原始业务日志、pcap、凭据及实验运行环境不作为阅读附件收录；相应链接会显示来源位置说明。

若PDF未内嵌显示，点击“独立打开PDF”。本地文件模式下书签等功能受浏览器本地存储策略影响，不能视为跨电脑云同步。

## 维护与核验

普通阅读不需要运行以下命令。导出器用于原始研究工作区，依赖Python的`markdown-it-py`、Poppler的`pdfinfo`及Node.js/KaTeX；不会修改原研究文档。

```bash
python3 tools/build_reader.py --workspace /path/to/oiwireless
python3 tools/validate_reader.py
```

本次属于文档展示和等价排版的非通信工程整理，**3GPP/新增数学推导不适用**。没有改变通信代码、配置、模型、公式含义或已有实验测量值。来源、验证与已知限制见`校验/`及`records/`。

KaTeX遵循其MIT许可，许可随`网页/vendor/katex/LICENSE`保存。论文、教材及3GPP协议的原有权利归各自权利人；本仓库用于用户已有资料的个人阅读整理。
