# TEST-048 PPT 生成与最终核验

整理始于 2026-10-16，最终检查完成于 2026-10-19。此测试只核验研究汇报产物，不代替网络实验。

## 实际命令

工作目录：`/home/lbh/oiwireless/analysis-presentations/tdd-20261016/build`。

1. 缓存 Node 执行 `build.mjs`，生成初稿与逐页 PNG。
2. 缓存 Node 执行 `finalize.mjs`，读取 candidate.pptx，校验并导出最终文件。
3. 缓存 Node 执行 `render-final.mjs`，重新导入最终 PPTX 并渲染全部 21 页。

Node 绝对路径：`/home/lbh/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node`。

## 失败与修正

- 首次沙箱执行 finalizer 时，Python 子进程返回 EPERM。没有关闭校验，获得环境授权后继续。
- 第二次执行缺少 RUNTIME_NODE_MODULES，第一方导入检查失败。显式设置为缓存 node/node_modules 后通过，未安装替代依赖。
- 初稿结论页有单独换行的句号。缩短句子后重新导出并检查。
- 在首版 20 页之后补入原 10 Mbps 配比时延模型，最终 21 页。

- 21 页、16:9。11 张原生可编辑表格，1 个原生柱状图，5 张既有研究图片。
- 包结构、页面尺寸、标题适配、指定表格页、字体策略均通过，最终布局 finding_count 为 0。
- 图表包含两组序列与六个数值，已打包为嵌入工作簿快照；范围与缓存核对通过。该工作簿只保存本轮源数据值，不声称存在原始工作簿公式。
- 第一方工具重新导入最终文件成功。再次渲染并逐页打开全部 21 页，未见缺字、截断、重叠或数值错配。
- 初稿与重新导入的 PNG 字节不同，因此没有假定二者相同，而是全部重新目视检查。各最终预览哈希保存在本地 build/final-preview-hashes.json。
