# TEST-011 命令发现与错误模式组合

在 cmake_targets/ran_build/build 执行 ./nr-softmodem --help（退出255，帮助文本正常打印），./nr-uesoftmodem --help（退出0），输出保存于 /tmp/oi-tdd-gnb-help.txt 和 /tmp/oi-tdd-ue-help.txt。

失败命令：
```bash
timeout --signal=INT --kill-after=3s 12s ./nr-softmodem -O ../../../research/latency-analysis/results/tdd1/rfsim-configs-01/gnb-120k-d3-u1-rfsim.conf --rfsim --phy-test --sa --rfsimulator.serveraddr server --thread-pool N --parallel-config PARALLEL_SINGLE_THREAD
```

退出255，断言“Standalone mode and phy_test are mutually exclusive”。日志 results/tdd1/preflight/rfsim-d3-u1.txt。纠正：PHY 初始化检查删除 --sa，不能把这个模式测试当作完整 SA 接入。未修改 OAI 来绕过断言。
