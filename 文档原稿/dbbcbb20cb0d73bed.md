# 实际测试：测过哪些批次、如何判断成功、失败后怎么处理

所有 347 条原 TEST 的命令、环境、输出、结果与局限见 [05 全索引](05_全部修改与测试记录索引.md)和 14 份测试附录。本文件把它们按真实研究批次归类，不把每条检查或“已启动”都算一次无线实验。

## 一、测试层次不能混用

|层次|实际验证什么|不能代替什么|
|---|---|---|
|文件/来源/规则/Git|原始保护、哈希、协议可读、来源/分支与同步|没有验证业务性能|
|语法/CLI/准备/冻结|脚本可解析、参数/计划/容量/身份正确|没有运行 gNB+UE，不可提前写实验通过|
|数学/模型/独立夹具|声明假设下的等待/TBS/队列/统计恒等式|不是完整 OAI 协议栈或真实硬件认证|
|生产 C 单元/内存/字节|抽取真实函数或生产 helper 的边界、内存与 ON/OFF 字节|不单独证明全栈接入和业务|
|完整编译|指定源代码能构建 gNB/UE/模块，实际 ELF 身份明确|不代表软件运行所有条件都通过|
|仅 gNB 预检查|历史配置在某启动路径到什么阶段|不能支持端到端时延或完整配比可行性|
|SA 接入/ping|UE 接入、TUN、路径和连通/RTT|不是 UL/DL 单向业务或尾分位|
|完整 UL/DL 编号 UDP|真实协议栈/路由/应用/N3/TUN 完整关联，按 UE 统计|仍是 RFsim 壁钟；不是纯空口或真实射频/机械闭环|
|内部观察/离线复核|事件完整、分段覆盖、TB/授权、同包区间、开销、积压|不把混合段/P99加和当独立纯层耗时|
|图/文档交付|数字/来源一致、页面/图例可读|不产生新无线数据或算法收益|

## 三、哪些失败导致了什么后续动作

|观察到的问题|测到了哪里|改什么/是否重测|不能改写成什么|
|---|---|---|---|
|模型末包越界|模型计算失败，不是无线失败|修结束边界，模型单元和矩阵重跑|不能说旧失败矩阵已经完整|
|gNB成功行但socket失败/旧1:3断言|仅启动路径|改成功判据，保留断言，后来另做完整SA|不能说旧PHY失败=配比违反协议|
|默认DRB SDAP头前提错误|旧完整业务可能成功，但配置前提有实质问题|生成新配置、必要完整栈重测，旧表转历史|不能加1字节常数就叫新实测|
|N3写死QFI0/UPF冷DL|控制/数据字段诊断和冷/预检对照|真实C用控制面QFI，明确单流保护与UL预检|不能说冷DL根因已全面修复|
|SearchSpace空字段崩溃线索|多UE接入/配置阶段失败|生产函数发布/锁修复，六项有限全栈回归|不能跳断言/塞默认配置强过|
|SSB65重复高位、SSB33控制方向|不同阶段的两种问题|先真实C幂等修复，再配置方向修正，各自冻结/重测|不能取模或挑SSB1成功轮替代|
|PHY μ 观察错误/分析器变量错|应用业务完整，新图关联失败|改观察来源/离线条件，新程序纠正先导|不能写首次新图已经通过|
|PDCP trace溢出|业务可完整，但内部数据不完整|独立容量预算、重建并重测全新组|不能补造丢事件、放宽dropped0|
|服务中断/PFCP前检未过|控制进程或编号业务前|持久日志、严格空业务接续、双根账本|不能把没启动的业务当无线丢包|
|TDD长组TUN捕获drop2|应用/N3完整但四边界门槛FAIL|失败应用样本单列，同参数一次接续复测|不能用应用收齐覆盖抓包失败|
|短MAC子头规则不符|旧路径实际触发，旧完整业务仍是旧程序事实|真实C短/长头与预算修正、独立构建、必要六新条件|不能把旧所有五阶段改标签叫新程序|
|RFsim实际模块路径不符|新修正程序首项编号UDP前停止|显式新build搜索路径、保留路径/SHA门槛接续|不能声称测到了该项UDP时延|
|事后总包数断言作者错|新N1业务和全图已完整|修控制器N相关计数，独立复核后明确复用N1|不能说N1真实丢包或虚写又测一次|
|路径/模块名/NumPy/图例/字体/链接|通常是准备或结束后的离线/交付|按实际阶段修脚本并重核，不无谓重跑无线|不能与PHY/RAN失败混在一起|

## 四、每条测试怎样判断“完成到哪里”

阅读原 TEST 时依次找：实际工作目录和命令、源/程序/配置/冻结身份、开始的最后阶段、业务是否发包、应用/抓包/内部事件各自是否完整、直接失败与根因是否定位、后续是否同程序/同参数复测。没有退出或结束证据的“已启动”不能当完成，没有数据的阶段不填0。

均值相加只用于相同包和同一时钟口径；各段 P99 不直接相加。短4000/UE不冒充可靠长P99.9；同尾包的条件均值与逐段边际分位不同。没有独立传输/重传/重组探针时，不给混合区间拆出虚假的每层毫秒值。

## 五、本轮不重跑旧实验

本次只汇总已存在的修改、版本和测试证据，不重新启动 RFsim，也没有实施算法。历史“修改后重测”的结果以原 TEST 为准；当前下一步是否恢复新实验，由你的最新指令和接续边界决定。缺所需协议仍必须按 AGENTS 停止，本次历史文档工程没有新增协议需求。
