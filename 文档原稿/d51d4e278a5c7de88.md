# TEST-012 手动 PHY 初始化

工作目录 cmake_targets/ran_build/build。分别执行以下模板，D3/U1 的 seconds=12，D2/U2 的 seconds=8：
```bash
timeout --signal=INT --kill-after=3s <seconds>s ./nr-softmodem -O ../../../research/latency-analysis/results/tdd1/rfsim-configs-01/gnb-120k-d<D>-u<U>-rfsim.conf --rfsim --phy-test --rfsimulator.serveraddr server --thread-pool N --parallel-config PARALLEL_SINGLE_THREAD
```

两次均退出124（预定 timeout），日志 rfsim-d3-u1-02.txt、rfsim-d2-u2-02.txt：模拟器加载、RUs configured、RU 0 RF started；无断言。gNB-only，没有 UE，日志“generating void samples”是空输入，不是有效业务流量。存在无 SYS_NICE 能力提醒，但本测试不测处理时延，不把它归为无线时延。

复核补充：这些沙箱日志还有 socket 权限错误，因此不认定真正 RFsim 启动成功；TEST-017 才是沙箱外启动证据。
