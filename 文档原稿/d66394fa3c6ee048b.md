# TEST-024 RFsim初始化

在获准的沙箱外执行（环境禁止沙箱内socket）：
```bash
python3 research/latency-analysis/scs2/rfsim_scs_check.py --configs research/latency-analysis/results/scs2/rfsim-configs-01 --output research/latency-analysis/results/scs2/rfsim-check-01 > research/latency-analysis/results/scs2/preflight/rfsim_checks.txt 2>&1
```

脚本退出0，30kHz/273PRB/D3U1、120kHz/66PRB/D14U5两项均加载RFsim、本地socket和PHY启动，无断言/设备启动错误；每个gNB返回124（6秒计划终止）。status.json保存完整命令、退出码和范围。

这是PHY测试模式的gNB-only验证，不是软件UE注册或真实业务。未使用真实射频。不把频段不同的两份初始化日志作为纯SCS时延实测。
