论文以用户已有英文PDF为主，首选本地3GPP原文核验字段边界；网页只补核作者仓库、版本和数学原始出处。没有登录学生账户，没有新增协议下载，没有修改摄像头内容、C程序、NR配置、二进制或既有测量值。当前所需协议可读；后续实施若缺必要原文，执行AGENTS置顶停止规则。

新会话先读AGENTS、START_HERE、本文和最新CHG/TEST。这里的公式为候选设计或明确引用的数学方法，不能当已经在OAI验证的收益。默认不自动开始算法实现。未来决定方向后，须另写具体C变更、变量/单位、来源、预声明数据和基线，再实施和测试。

来源核验命令（仓库根目录）：

```bash
/usr/bin/python3 -B research/latency-analysis/algorithm-options/verify_sources.py
/usr/bin/python3 -B research/latency-analysis/source_audit/validate_reference_audit.py
```

`verify_sources.py`只查原文哈希、可读性/页数、三份规则一致性、旧251输入未变及本地链接，并保存`evidence/source_validation.json`；这是资料核验Python，**不是NR协议栈修改或调度算法仿真**。需要本机原文和旧实验冻结输入，其他机器缺这些时会明确失败，不会自动下载或重跑RAN。
