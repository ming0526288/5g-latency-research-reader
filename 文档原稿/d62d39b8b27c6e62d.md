## 实际做了什么

在同机5GC、gNB和软件UE完整RFsim链上，修正TS38.321 V19.4.0 §6.2.1的短MAC SDU子头及预算，再测1/4/8UE与8UE两档负载。共166500包完整关联、148000统计、37条流。独立核376891条初传段关联与307437个TB字节分区。

原先小于256字节的MAC SDU仍用长头；现在按规范用短头。C负责真实UE组包/协议栈，Python负责启动隔离、编号UDP、抓包和离线关联统计，并未将OAI C协议栈替换成Python模型。本次纠正属于标准要求，不是时延优化算法。

固定120kHz、66PRB、MCS上限9、0.625ms与3完整D＋S＋1完整U，全部观察ON。1/4UE总4Mbps；8UE总3/4Mbps两轮。首次库路径检查失败在业务前停止；第二root N1业务完成但外层包数断言写错，独立核验后复用这一项，最终root只新跑后五项。失败、原始包和慢包均保留。

## 名词表

|名词|直观含义|读结果时注意|
|---|---|---|
|UE|软件终端|本次N=1、4、8，多个进程/namespace|
|gNB|5G基站|为不同UE安排无线资源|
|5GC / UPF|核心网 / 用户面转发功能|本次接收应用在UPF网络环境，AMF/SMF不转发每个业务包|
|RFsim|软件交换无线样本|无射频，墙钟未必等于标称无线时间|
|UL / DL|终端向网络 / 网络向终端|本次修正后只给UL新基准|
|TDD|上下行在时间上分配方向|要同时看周期、槽、符号与授权位置|
|D:U|完整D槽数比完整U槽数|本3:1另有一个S，不是OFDM符号比|
|S|含不同方向/灵活符号的边界槽|本例6D/4F/4U为工程输入，标准未逐项指定此配比|
|SCS|子载波间隔|本次120kHz；其他SCS修正后业务待重测|
|slot|时隙|120kHz标称0.125ms，RFsim墙钟不保证按此推进|
|MCS / PRB|调制编码选择 / 频域资源单位|本次MCS上限9、66PRB；不是摄像头驱动14/25模式|
|grant / 授权|gNB告诉UE使用哪批资源|已准备、UE接收、实际发送是不同事件|
|K2|相关下行控制到上行目标的槽偏移|本次名义4槽，不等于每包固定0.5ms墙钟|
|TB|交给PHY的一块传输数据|一个包可跨TB，一个TB也可装多个包片段|
|SDU / PDU|一层收到的上层数据 / 该层输出数据|RLC PDU在此处就是MAC SDU，不能混叫UDP payload|
|RLC / segment|无线链路控制层 / 它拆出的片段|统计初传全部SO覆盖，segment数与唯一TB数不同|
|MAC子头 / F / L|组包头 / 长度格式 / 长度字段|小于256字节的普通SDU用F0/L8、子头2字节|
|CE / padding|MAC控制元素 / 填充字节|CE和RLC头有实际作用，不能统称浪费|
|CRC / HARQ|接收校验 / 快速重传机制|本统计样本未见失败/重传，不代表所有无线环境都不会发生|
|QFI|QoS流标识|本次核QFI9，避免错误用户面配置|
|P99|样本99%分位阈值|不是平均、最大或最慢40包的均值|
|P99.9|更高尾分位|本次每UE4000样本不足以认证稳定总体尾部|
|W|RLC接纳到第一段初传|混合等待，不是纯CPU排队|
|S|第一段至最后一段初传跨度|包含分段期间服务间隔，不能另加跨TB跨度|
|R|最后初传至gNB RLC完整交付|含PHY/gNB处理/交付等混合过程|
|O|RLC区间之外的APP链路时间|和W/S/R按同包集均值可加|
|同40包|每流按总时延选最慢40个包|对这一批分别求分段均值，不能拼接各段P99|

注意：TDD的S是边界槽，时延分段的S是序列化跨度，语境不同。Word第4页外部图A/B/C/D与内部小写a/b/c/d也不同；内部公式时刻统一ms，原始*_ns差值除10^6。

## 这些分析对优化有什么用

有用，因为先确定慢在什么机制，才知道算法该作用在哪里。当前8UE有积压授权间隔P99约24至35ms，慢包仍有明显开始服务前等待；跨TB在1UE也常见，但8UE跨TB服务间隔更长。应优先观察调度资格、未被选中原因和轮次执行节奏。

负载提高时padding反而降低，且保守判据未发现原有编号积压跨整个组包仍未完成又留至少8字节padding的TB；目前不支持先把“大padding”当主要原因。14.8万统计包重传0，也不支持先假定主要是HARQ。CPU4约99%忙与RFsim推进慢提供主机关联证据，但不能说所有慢包都是硬件CPU造成。

这些结果尚未证明某个算法有效。下一步先只读观察原因和探针开销；算法实现继续不做。不同TDD、不同SCS、多UE、分层和尾部五类分析仍必做，其他修正后工作点及长P99.9未完成，不因旧组曾成功就改标签成新基准。
