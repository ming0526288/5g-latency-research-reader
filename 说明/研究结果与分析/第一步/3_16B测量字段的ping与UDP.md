# 3. 16 B 测量字段的 ping 与 UDP 对比

[知识点](../../算法知识点说明/十二步知识点/第一步/3_16B测量字段的ping与UDP.md) · [启动命令](../../启动命令/第一步/3_16B测量字段的ping与UDP.md) · [结果与分析](3_16B测量字段的ping与UDP.md) · [返回第一步结果与分析](../第一步结果与分析.md)

本项暂以 16 B 为测量字段长度、256 B 为两种工具的数据总长。ping 的本机 timeval 和 UDP 的事务标记恰好都为 16 B，功能不同；下面不是 ping -s 16 或 16 B UDP 数据的实测。若需要数据总长 16 B，当前仍属未测项。

|工具|轮次|完整/统计|工具 RTT 平均 / ms|工具 P99 / ms|共同 TUN RTT 平均 / ms|共同 TUN P99 / ms|
|---|---:|---:|---:|---:|---:|---:|
|ping|1|2200/2000|2.362390|3.500000|2.359612|3.491862|
|udp|1|2200/2000|2.281553|3.540496|2.269555|3.525426|
|udp|2|2200/2000|2.290166|3.592956|2.279439|3.580134|
|ping|2|2200/2000|2.280265|3.700300|2.277620|3.699025|
|ping|3|2200/2000|2.417525|3.610000|2.414583|3.609243|
|udp|3|2200/2000|2.290742|3.670615|2.279359|3.658690|

两种工具的原生计时切点和回复处理不同；共同 TUN 边界用于辅助比较。实际间隔也不完全相同，不能把差值全解释成 UDP 或 ping 的协议优势。完整条件和包长敏感性见第 4 项；这些六轮均已包含在第 4 项，不另计次数。
