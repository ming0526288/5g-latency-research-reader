# PF 下三 UE 前两台同时发、第三台排队

**基站暂时停发前两台的空闲探测授权后，第三台平均 RTT 从排队基线的 7.754 ms 降到 2.415 ms。** 三台全部收齐的平均时间从 **11.562 ms 降到 6.407 ms**，仍高于预想的 5 ms。本页保留原排队基线，下方补入暂停空闲探测的新测结果。

## 我怎么测

我沿用此前 **100 MHz、120 kHz、66 PRB、DDDSU、PF、门限 0、空闲探测后置、56 B ping** 的 RFsim 配置。三台 UE 按 UE 1、UE 2、UE 3 的顺序接入，在测量期间保持连接。每批先向前两台发出指令，两台收到 ping 回复后再让第三台发。每台实际发出数据都由原生 `ping` 命令完成。为关联三台的同一批请求，本次在原有填充区写入批次标记，包长仍为 56 B。

每批从前两台中第一条请求经过 UE TUN 时开始计时，到第三台回复经过 UE TUN 时结束。前两台发包时刻的间隔中位数为 **0.001 ms**。180 批统计里有 **179 批**的两段往返时间重叠，另有一批发包错开，保留在结果中。批起点的平均实测间隔为 **20.072 ms**。沿用原核心网，逐包核对 UE TUN 和 N3，四处抓包均无内核丢包。

## 旧并行基线与这次排队

|方式|每 UE 发出／收到|UE 1 / 2 / 3 平均 RTT（ms）|UE 1 / 2 / 3 P99（ms）|
|---|---|---|---|
|三路并行，复用已有数据|各 200/200|2.241 / 2.292 / 7.187|2.868 / 3.493 / 11.700|
|前两台同批，第三台排队，原空闲探测|各 200/200|2.525 / 2.534 / 7.754|3.518 / 3.599 / 14.000|
|前两台同批，第三台排队，短时暂停前两台的空闲探测|各 200/200|2.494 / 2.512 / 2.415|3.536 / 3.352 / 3.046|

并行组的三条 ping 独立运行，没有共同的批次编号，所以保留每台的 RTT。两个排队组按相同起止边界统计整批时间。并行组的 **7.187 ms** 是 UE 3 单台的 RTT。[原三 UE 并行短测](门限0下第三个UE的接入验证.md)

## 这 11.562 ms 花在哪里

|同一批的计时区间|平均用时|
|---|---:|
|第一条请求发出，到前两台都收到回复|2.637 ms|
|前两台都收到回复，到第三台请求实际发出|1.174 ms|
|第三台请求发出，到第三台收到回复|7.751 ms|
|整批收齐|**11.562 ms**|

原排队组第三台的往返时延中，从 UE TUN 到 N3 的上行段平均 **6.815 ms**，N3 之间的转发和回复段 **0.063 ms**，N3 到 UE TUN 的下行段 **0.873 ms**。只把第三台安排到后面时，它的上行仍占了大头。抓包能定位到上行段，具体授权事件要结合基站调度记录。

## 新测 暂停前两台的空闲探测

三台保持接入。前两台的回复收齐后，业务程序先等基站确认暂停，再让 UE 3 发出同批 ping。UE 3 回复或超时后恢复。基站只在空闲探测后置分支里跳过前两台的纯空闲候选。有实际数据、收到调度请求和需要重传时继续按原规则处理。第三台的探测和授权保持原规则。射频配置、包长、批次数和预热沿用原排队组，仍以 20 ms 为目标批间隔。

|测量指标|原排队组，复用|暂停前两台探测，新测|
|---|---:|---:|
|前两台收齐平均用时|2.637 ms|2.568 ms|
|触发第三台发包平均用时|1.174 ms|1.428 ms|
|第三台 TUN 往返平均时延|7.751 ms|2.411 ms|
|第三台 TUN → N3 上行段均值|6.815 ms|1.480 ms|
|整批收齐平均用时|11.562 ms|6.407 ms|
|整批收齐 P99|18.521 ms|8.596 ms|
|整批在 5 ms 内收齐|0/180 批|1/180 批|

180 个统计批次都取得了暂停和恢复确认。基站分别跳过前两台各 **721 次**符合条件的空闲探测候选。第三台在暂停窗口取得 **715 次**探测授权，覆盖全部 180 个统计批次。暂停确认平均用了 **0.252 ms**，已经计入触发段。第三台时延的缩短主要发生在上行。

原排队组复用此前实测，新组用带暂停控制的试验构建完成。这是单次短测和跨批次参照。授权计数说明措施实际生效，尚未把每个 ping 对应到具体一条授权。这个暂停窗口是本项目在基站中验证的策略，3GPP TS 38.300 V19.4.0 §10.3、TS 38.321 V19.4.0 §5.4.1、§5.4.4、§5.4.5 定义了授权和需求报告流程。
