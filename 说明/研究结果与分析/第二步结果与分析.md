6600/6600 是每 UE 三轮累计发出／收到次数；每轮 2200 次，前 200 次预热，三轮实际统计 6000 次。均值中的斜杠按 UE 1、UE 2、UE 3 顺序排列，不表示两轮或两种负载。表内统一为每 UE 目标 50 包／秒、56 B 数据区的轻负载，ping 测原生 RTT，UDP 测应用请求—回复 RTT。

|UE 数|每 UE 目标请求包／秒|全部 UE 目标请求包／秒|全部 UE 上行请求数据区／Mbps|
|---|---:|---:|---:|
|1|50|50|0.0224|
|2|50|100|0.0448|
|3|50|150|0.0672|

每 UE 目标间隔 20 ms，56 × 8 × 50 = 22400 bit/s。普通内层 IPv4 包为 84 B，单 UE 请求流量约 0.0336 Mbps；等长下行回复另算。这里不含控制信令、重传、空授权或其他无线开销，不是 OAI／3GPP 的默认工业业务。

门限 0 的单 UE ping/UDP 复用第一步三轮，未重新发包；其网络环境与多 UE 隔离网络不同。门限 1 UDP 沿用已完成的正式矩阵，不重复测。新增多 UE ping、门限 0 双 UE UDP 均独立保存分轮记录，不与短测合池。

## 本批完成范围

可运行条件的这批三轮补测已经补齐，完成后暂停。门限 0 三 UE 仍未完成共同接入，不能填时延。高负载、逐包 SR／授权／重传／队列事件及慢包根因尚未在本批补测中完成，第二步整体仍为部分完成。

原生 ping 分终端自然启动，保留实际间隔和共同统计时段；门限 0 双 UE 有一轮业务时段未重叠，原记录单列保留，并补了一轮相同条件的并发测量后才计入上表。没有依据时延大小筛选轮次。UDP 业务按共同应用起点发包，不控制 RFsim 启动相位。

这两表反映相应成功运行的结果；既有接入异常、单 UE 用户面停滞和未重叠记录都保留在对应页及实验记录，不用 0 ms 或别组数字填补。RTT 不是纯空口单向时延，也不是机械臂物理执行闭环；P99 不由上下行 P99 相加。
