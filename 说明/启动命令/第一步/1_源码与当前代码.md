## 核心网、基站、UE 分终端直接启动

本轮使用原核心网、研究副本的实际构建目录。当前配置文件为 `gnb1.sa.band261.fr2.66PRB.5slot.low-latency.mcs9.sync1.dpdk.conf`，开启已编译的 RFsim 混合槽下行段末同步 C 处理；不是原配置只换名。无线配置仍为 n261、27.54756 GHz、120 kHz、66 PRB、0.625 ms TDD，PF、HOL 关闭、MCS 上限 9、空闲授权资格 0。

### 终端 1：原核心网

```bash
cd ~/oiwireless/oiwireless-5gc-deploy
./run-5gc.sh
```

### 终端 2：现在代码 gNB

```bash
cd ~/oiwireless/oi-wireless-ran-ping-slot-validation/cmake_targets/ran_build/build
sudo ./nr-softmodem -O /home/lbh/oiwireless/oi-wireless-ran-ping-slot-validation/research/latency-analysis/rfsim-slot-sync-v1/configs/gnb1.sa.band261.fr2.66PRB.5slot.low-latency.mcs9.sync1.dpdk.conf --sa --rfsim --rfsimulator.serveraddr server
```

### 终端 3：现在代码 UE

等 gNB 报告 RF 已启动，再另开终端：

```bash
cd ~/oiwireless/oi-wireless-ran-ping-slot-validation/cmake_targets/ran_build/build
sudo ./nr-uesoftmodem --band 261 -C 27547560000 -r 66 --numerology 3 --ssb 301 --sa -O ../../../targets/PROJECTS/GENERIC-NR-5GC/CONF/ue.oiwireless.conf --ue-txgain 0 --ue-rxgain 20 --ue-fo-compensation --rfsim --rfsimulator.serveraddr 127.0.0.1
```

两端均不加 `--continuous-tx` 或额外线程池。127.0.0.1 是本机 RFsim 服务地址，不是 UE 业务地址。等待 UE 接入并配置 TUN 地址；TCP 已连接不能代替接入通过。

### 终端 4：核地址和路由，再检查用户面

```bash
ip -4 addr show dev oaitun_ue1
ip -4 route get 172.11.200.25 oif oaitun_ue1
ping -c 20 -I oaitun_ue1 172.11.200.25
```

本轮读取到 UE 业务地址 192.169.0.6，实际 5QI 9/QFI 9 已从接入控制捕获核验，TUN 和 UPF 回程均核查；20 包可达性检查不计正式统计。再次运行应重新读取，不能照抄历史业务地址。

## 两项共用的正式 56 B ping

```bash
ping -D -n -I oaitun_ue1 -c 2200 -s 56 -i 0.02 -W 2 172.11.200.25
```

每轮前 200 包预热、后 2000 包统计，共三轮。第 1 项现在代码和第 2 项采用同一组三轮，结果必须一致；第 4 项也引用它。只执行此命令得到 ping 输出，正式实验还同步进行 TUN/N3 捕获与事务关联。

## 最开始源码：另一个程序组

停止自己本次 gNB/UE 后，再切换到原始目录；不要两组同时争用 4043 和同一个 TUN。原核心保持原部署。

```bash
cd ~/oiwireless/oi-wireless-ran/cmake_targets/ran_build/build
sudo ./nr-softmodem -O /home/lbh/oiwireless/oi-wireless-ran-latency-analysis/research/latency-analysis/step1-native-v1/configs/gnb1.sa.band261.fr2.66PRB.5slot.low-latency.mcs9.dpdk.conf --sa --rfsim --rfsimulator.serveraddr server
```

另开终端进入原始 build，执行上面同参数 UE 命令。这里采用共同无线基底，原运行文件和原配置文件均不改，不加同步修复。用户最初的 `gnb1.sa.band261.fr2.66PRB.5slot.dpdk.conf` 是另一套历史配置，不能混称同条件。原始封装/标记局限和启动状态须单独报告，未完成接入不能测 RTT。

## 停止与依据

各自终端 Ctrl-C，只停止自己的进程；原核心保留，不做全局 pkill。完整格式/捕获命令见[第 2 项](2_56B数据区的ping与UDP.md)。配置来源和测量边界见对应知识页；同步开关、MCS 上限、资格 0、包数和间隔均为实现/实验选择，不是协议强制最优参数。
