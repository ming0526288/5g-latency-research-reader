# 独立实验启动命令

从[启动命令总目录](启动命令总目录.md)选题目可直达对应小节。下文整理的是实际运行记录。每个工作点使用自己的构建、配置和参数。复用已有结果时可以直接查对应结果页。

## 公共准备

核心网、gNB、每台 UE 和业务分别开独立终端。原核心网已在线时沿用。若本机尚未运行原部署，在核心网终端执行：


```bash
cd ~/oiwireless/oiwireless-5gc-deploy
./run-5gc.sh
```

gNB 报告 RF 已启动后再启动 UE。有多台 UE 时，上一台的 TUN IPv4 配置完成后再启动下一台。检查前往 `172.11.200.25` 的路径经过 `oaitun_ue1`，业务完成后在本轮各终端按 Ctrl-C 停止自己的进程。

下列变量是本机已有目录。把所用变量赋值粘贴到各自的终端。每轮的 `CASE` 要选自己的绝对目录，并在涉及探针时先建探针目录。抓包工具的输出子目录由工具创建，给 `--root` 的那一级须尚不存在。私有 UE 配置沿用各命名空间已登记的本机文件。


```bash
LAB=/home/lbh/oiwireless
REPO="$LAB/oi-wireless-ran-latency-analysis"
AUDIT="$LAB/analysis-source-audit"
UE_BUILD="$LAB/oi-wireless-ran-ping-slot-validation/cmake_targets/ran_build/build"
ENV_DIR="$AUDIT/step2-multiue56-20261118/environment"
TOOLS="$REPO/research/latency-analysis/step2-multiue56-v1"
GNB100="$LAB/oi-wireless-ran-ping-slot-validation/research/latency-analysis/rfsim-slot-sync-v1/configs/gnb1.sa.band261.fr2.66PRB.5slot.low-latency.mcs9.sync1.dpdk.conf"
GNB100_GATE1="$TOOLS/configs/gnb1.sa.band261.fr2.66PRB.5slot.multiue.mcs9.inactivity1.sync1.dpdk.conf"
GNB200="$TOOLS/configs/gnb1.sa.band261.fr2.132PRB.5slot.multiue.mcs9.inactivity0.sync1.dpdk.conf"
GNB200_DDSUU="$AUDIT/step2-scheme3-tdd-20261120/gnb1.sa.band261.fr2.132PRB.5slot.DDSUU.mcs9.inactivity0.sync1.dpdk.conf"
RESIDUAL_BUILD="$AUDIT/step2-three-ue-admission-20261119/residual-build-v2"
CG2_BUILD="$AUDIT/step2-cg-type2-20261120/build-02"
BOOT_BUILD="$AUDIT/step2-scheme3-plan-b-20261120/build-v2"
```

每轮在一个终端先生成并显示 `CASE`，再把同一个绝对路径赋给其他终端的 `CASE`。探针目录只在启用探针时创建。

```bash
CASE="$AUDIT/independent-replay-$(date +%Y%m%d-%H%M%S)"
printf '%s\n' "$CASE"
```

## 多 UE 通用命名空间命令

`N` 为 UE 编号减 1。每台 UE 在自己的终端设置 `N=0`、`N=1` 或 `N=2`。以下为 100 MHz、27.54756 GHz、66 PRB、SSB 偏移 301 的命令。单机非隔离试验的 UE 命令另列。


```bash
cd "$UE_BUILD"
N=0
sudo -n ip netns exec "s2m56u$N" ./nr-uesoftmodem --band 261 -C 27547560000 -r 66 --numerology 3 --ssb 301 --sa -O "$ENV_DIR/private/ue$N.conf" --ue-txgain 0 --ue-rxgain 20 --ue-fo-compensation --rfsim --rfsimulator.serveraddr "10.203.$((N+1)).1"
```

接入后在业务终端用同一 `N` 查看本轮网卡及路由。


```bash
sudo -n ip netns exec "s2m56u$N" ip -4 addr show dev oaitun_ue1
sudo -n ip netns exec "s2m56u$N" ip -4 route get 172.11.200.25 oif oaitun_ue1
```

## 独立 ping 与抓包

这组命令适用于标记为每 UE 200 次、56 B、20 ms 目标间隔的短测。联通检查或历史正式样本量以各题目说明为准。捕获终端设 `UE_COUNT=1`、`2` 或 `3`，须与实际接入并参与业务的 UE 台数一致。


```bash
sudo -n /usr/bin/python3 -B "$TOOLS/ping_capture.py" --environment "$ENV_DIR" --root "$CASE/packets" --ues "$UE_COUNT" --regime per-ue --packets 200 --warmup 20
```

等捕获终端显示 READY，每台 UE 在独立业务终端发包。全部结束后由一个终端创建结束标记。


```bash
sudo -n ip netns exec "s2m56u$N" ping -D -n -I oaitun_ue1 -c 200 -s 56 -i 0.02 -W 2 172.11.200.25 | tee "$CASE/packets/ue$N/ping.log"
```


```bash
touch "$CASE/packets/finish.request"
```

## PF 下三 UE 前两台同时发、第三台排队

[查看本项结果与分析](../研究结果与分析/PF下三UE前两台同时发第三台排队.md) · [返回启动命令总目录](启动命令总目录.md)

固定 100 MHz、门限 0 和空闲探测后置。三台 UE 均用[多 UE 通用命令](#多-ue-通用命名空间命令)逐台接入。原排队组 gNB 使用 TEST-675 的 `RESIDUAL_BUILD`：


```bash
cd "$RESIDUAL_BUILD"
sudo -n OAI_RESEARCH_PROBE_POLICY=residual ./nr-softmodem -O "$GNB100" --sa --rfsim --rfsimulator.serveraddr server
```

三台都已配置 TUN 且路由通过后，在业务终端执行。业务工具只协调每批的原生 ping、抓包和统计。


```bash
mkdir -p "$CASE"
sudo -n /usr/bin/python3 -B "$TOOLS/staggered_ping.py" --environment "$ENV_DIR" --root "$CASE/packets"
```

暂停探测组使用 TEST-676 的 `paused-build`。启动前用当轮新目录创建 56 字节控制文件，gNB 和业务终端使用同一绝对路径。


```bash
mkdir -p "$CASE"
CONTROL="$CASE/control.bin"
(umask 077; set -o noclobber; head -c 56 /dev/zero > "$CONTROL")
cd "$AUDIT/step2-ping-probe-pause-20261123/paused-build"
sudo -n OAI_RESEARCH_PROBE_POLICY=residual OAI_RESEARCH_PROBE_PAUSE_FILE="$CONTROL" ./nr-softmodem -O "$GNB100" --sa --rfsim --rfsimulator.serveraddr server
```

依次接入三台 UE 时，从响应日志核对每次新增的临时无线标识 RNTI，把前两台本轮的十六进制 RNTI 填入 `RNTI_1` 和 `RNTI_2`。随后在业务终端执行：


```bash
CONTROL="$CASE/control.bin"
sudo -n /usr/bin/python3 -B "$TOOLS/staggered_ping.py" --environment "$ENV_DIR" --root "$CASE/packets" --pause-file "$CONTROL" --pause-rntis "$RNTI_1" "$RNTI_2"
```

三台并行基线沿用 TEST-623 的[三 UE 后置短测](#门限-0-下第三个-ue-的接入验证)。单、双 UE 的短测沿用 TEST-679 与原双 UE 记录。
