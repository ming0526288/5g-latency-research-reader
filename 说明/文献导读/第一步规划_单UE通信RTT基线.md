# 第一步规划

**我的第一步是按下面五项梳理通信测量方法与实验基线。** 第 4、5 项已有数据，第 1、2 项尚未完成严格对照；第 3 项明确 16 B 的含义后引用对应工具记录，不冒称测过 16 B 数据包。此次只重排已有工作，没有新增实验。

## 我的第一步目标

用相同编号把知识、命令、结果接起来，确认代码、包内容、工具、包长与计时边界各自怎样影响比较。机械臂和汽车装配作为业务背景，本步只分析通信，不处理视觉或机械动作。

|实验|内容|验收与当前边界|
|---|---|---|
|1|原始源码与当前代码：统一用 ping 对照|两版本均用同一种 ping；原始 UE 接入失败，原始 RTT 仍待补|
|2|80 B 与 16 B 的 UDP 对比|总数据固定 256 B，分别用 80/16 B 测量头；现有输入不同，受控 A/B 待补|
|3|16 B 测量字段的 ping 与 UDP 对比|暂以两工具各 16 B 测量字段、总数据 256 B 整理；不是 16 B 包实测|
|4|各包长的 ping 与 UDP 对比|ping / UDP 各 56/256/1200 B，三轮，共18条件；报告原生与共同TUN边界|
|5|实验基线|选第4项UDP256三轮作后续参照，不新增运行/计数|

## 本步固定的测量要求

先核原文/版本/配置，排除路由旁路，核同一事务编号和时钟，再逐轮计算 RTT、分段和分位数。P99不相加，不把不同输入的两批差值解释成单变量收益。第3/4/5项共享的当前版本工作点为120 kHz/n261/66 PRB、PF、实际5QI9/QFI9、单UE RFsim；第1项原始程序配置单独记身份，不自动套同一启动参数。完整取值见结果第4/5项。
