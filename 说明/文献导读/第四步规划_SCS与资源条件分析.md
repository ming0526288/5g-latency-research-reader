# 第四步规划

状态：规划已建立，实验尚未执行。

本步主题：**不同 SCS 与资源条件的时延分析**。

## 我的目标

我检验时隙缩短后，应用 RTT 能否下降，以及处理、资源量、分段和重传是否抵消这一收益。

## 我需要的前提与数据

我需要前面可靠的业务与统计方法，以及频段、带宽、PRB、CP、TDD 机会分布、TDA/K2、SR 等支持表。改变 SCS 时，不能默认为其他条件天然相同。

## 我准备怎么做

- 我先在 n261 的支持范围内核验 60/120 kHz；30 kHz 采用支持它的 FR1 配置，跨频段差异单独披露，不全部归因于 SCS。
- 我单列 240 kHz 的频段、数据传输和本实现支持边界。只有核验可运行后才做业务；模型分析与未测项分别报告，不把网格或 SSB 参数当成业务支持证明。
- 我说明固定带宽、固定 PRB 或固定机会分布分别能控制什么；测 UL、DL、RTT、有效吞吐/完成情况，并分开记录无线槽标签与主机墙钟。

## 我完成后交付什么

我提交支持矩阵、实际配置、时隙/机会解释和同口径结果。未支持和失败条件给出原文或实现证据，不能用 0 代替未测，也不宣称 120 kHz 必定比 30 kHz 的总时延小。

## 我的依据与执行边界

- TS 38.211 V19.5.0 §4.2、§4.3.2；TS 38.104 V20.1.0 §5.3.2/§5.3.5，特别是 FR2 表 5.3.2-2、5.3.5-2；TS 38.214 V19.5.0 §6.4。
- P02 §II–IV，本地 PDF 第 2–3 页：参数集与处理/时延关系；P30 LatencyScope §VI，第 8–12 页：配置依赖。教材第 77–80、211–213 页。
