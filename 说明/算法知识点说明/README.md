# 算法知识点说明入口

网页版从“知识点 → 算法知识点”进入新版速览，再选择各算法。这里只维护阅读站唯一说明源稿；研究仓库旧稿保留历史身份。

- [七种调度算法速览](调度算法入门/00_调度算法速览.md)：用户要求的对照表、PF 入门公式及术语。
- 独立讲解：[RR](调度算法入门/RR_知识点说明.md)、[MT](调度算法入门/MT_知识点说明.md)、[PF](调度算法入门/PF_知识点说明.md)、[PB](调度算法入门/PB_知识点说明.md)、[EDF](调度算法入门/EDF_知识点说明.md)、[M-LWDF](调度算法入门/M-LWDF_知识点说明.md)、[QUEST](调度算法入门/QUEST_知识点说明.md)。每篇包含规则或公式、变量、例子、时延作用与来源。
- [通信与时延基础](00_通信与时延基础知识.md)：持续整理用户提问的学术化问法与回答；包含单位、上下行、包路径、精简字段、四时刻、多 UE 身份与分层测量边界。

以上新版知识用 `../knowledge.json` 的独立 topic 登记，运行 `python3 -B tools/update_knowledge.py` 生成；它们是现有算法的基础讲解，不创建新研究算法编号或已完成的结果页。七篇分开维护，速览仅做索引，不把各算法详细正文混写。

旧共同前置条件、旧 QUEST/AUGUSTE 详细知识和历史算法结果仍按 `../algorithms.json` 的 publication 归档，源稿与旧快照保留。新知识发布不取消旧归档；没有新增测量。未来实现新研究算法仍按阅读站 AGENTS 的 algorithm-notes/算法文档流程维护。
