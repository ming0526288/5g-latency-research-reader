# EDF：最早截止期限优先是什么意思

EDF 通常称 **Earliest Deadline First，最早截止期限优先**。可以理解成：**谁离自己的期限更近，就先考虑谁。** 它与单纯“谁等得最久”不同。

## 怎么算分数

如果包的到达时刻是 $a_i$、允许等待预算是 $D_i$，那么绝对截止时刻是 $d_i=a_i+D_i$。当前时刻为 $t$，已等待时间为 $H_i=t-a_i$，因此：

```math
s_i=d_i-t=D_i-H_i.
```

$s_i$ 是剩余时间，本文 $D_i$、$H_i$、$s_i$ 都用 ms。对尚未超时的包，选最小 $s_i$，等价于选最早截止时刻。

P24 对 UE 队首包使用的评分近似是：

```math
M_i=\frac{1}{\max(\varepsilon,D_i-H_i)}.
```

分数单位为 $\mathrm{ms}^{-1}$，越大越先考虑；$\varepsilon$ 是防止除零的小正时间。所有过期包被截到同一分母后，还需要明确并列和过期处理，不能把这种实现直接等同于全部情况下的逐包 EDF。

## 两个 UE 的例子

|UE|教学预算 $D_i$|已等待 $H_i$|剩余时间|分数|
|---|---:|---:|---:|---:|
|A|20 ms|17 ms|3 ms|1 / 3|
|B|5 ms|4 ms|1 ms|1|

**先考虑 B。** 虽然 A 等了 17 ms，比 B 久，但 B 离期限只剩 1 ms。这里的预算是教学假设，不是本实验已选的标准 5QI 或 RTT 期限。

## 对时延有什么用

EDF 直接照顾临近期限的数据，适合做时延对照。但单纯 EDF 不看当前传输效率；资源不足或无线条件差时，先排到也不代表能及时发完，更不保证应用通信 RTT 达标。
