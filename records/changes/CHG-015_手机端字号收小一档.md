# CHG-015 手机端字号收小一档

2026-11-03。用户希望手机端字体再小一些、更协调；按该偏好做一档微调，桌面保持CHG-014的阅读字号。

在 `网页/style.css` 末尾的 `@media screen and (max-width:740px)` 中集中维护：正文17→16px、行高1.85；导航/卡片说明16→15px；结果标题17→16px、来源/图注14→13px；文档主标题27→25px、二级标题23→21px、算法卡片标题24→22px，表格16→15px、代码15→14px。数值按常用16px根字号，以rem定义。搜索输入仍16px，控件最小尺寸、字体家族与公式专用字体保持；不通过缩小根字号连带改动全站。

规则限手机屏幕，不改变桌面18px正文/16px导航与卡片说明、打印11pt或现有源稿/图/公式。更新README/AGENTS/接续说明中的当前字号；13px是手机辅助信息层级，不是新的正文大小或标准最小值。

纯网页排版，3GPP/通信数学推导不适用，未新增研究、改通信参数或运行实验。实际核验见TEST-016；继续仅本地提交，不推送。
