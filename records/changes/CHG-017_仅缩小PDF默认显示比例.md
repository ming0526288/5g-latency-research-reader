# CHG-017 仅缩小 PDF 默认显示比例

用户先表示字体偏大，随后明确“其他地方的字体不变，我指的是 PDF 内部的字体”。临时网页字号修改已撤回；网页 CSS、AGENTS 字号规则无本项差异。

仅将 `网页/app.js` 中论文原文、中文 PDF、中文翻页与协议 PDF 的 URL 显示参数由 `view=FitH` 改为 `zoom=95`，让阅读器默认采用 95% 显示。独立打开的链接沿用该参数。没有重排 PDF 或修改 PDF 内嵌字体，网页其他字号保持既有设置。95% 是固定绝对缩放值，不等于适应宽度结果的 95%；用户可在 PDF 工具栏自行调整。

README 与阅读字体接续同步说明，协议阅读交互测试预期更新为 95%。不恢复暂停的翻译、引用更换或通信实验。非通信界面工程，3GPP/通信数学推导不适用。检查见 TEST-018，中央记录 CHG372/TEST522。
