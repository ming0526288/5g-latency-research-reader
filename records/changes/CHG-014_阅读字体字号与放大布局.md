# CHG-014 阅读字体、字号与放大布局

2026-11-03。用户指出字体偏小，要求检查网站常用字号并给出合适字体。仅调整网页排版，3GPP/通信数学推导不适用；未修改研究正文、公式定义、参数、测量值或实验状态。

## 修改

- `网页/style.css`统一字体和层级：英文/数字Arial优先；中文由系统按苹方、微软雅黑、Noto Sans CJK SC、Noto Sans SC、sans-serif顺序回退。只指定本机字体，不下载、不新增字体文件；各电脑实际安装字体可能不同。代码保留Consolas等宽栈，公式保留KaTeX/数学字体。
- 常用16px根字号下，正文由15px改为18px，窄屏由14px改为17px；导航13→16px；卡片说明13→16px；结果标题13→17px；来源10→14px；表格12/11→16px；图注和多数辅助文字11/12→14px。标题按层级放大，正文行高1.9。装饰标记和数字计数有独立字号，不把14px宣称为所有元素统一下限。
- 屏幕字号以rem表达并尊重浏览器根字号，打印正文仍为既有11pt。导航宽度适度扩大但保持固定布局宽度，避免文字放大后侧栏也加倍挤压阅读区；顶部高度、正文顶部留白和锚点滚动留白随文字偏好变化。来源标签独占一行，控件可换行；窄屏卡片单列，搜索输入可收缩。
- 浅色主题辅助文字改为`#58675f`，提高图注/说明可读性；对背景/白卡片/浅绿底的对比度约5.69/5.97/5.26。深色原辅助文字保持，所测对比度6.60/5.93/4.69。此为选定色对检查，不是全站可访问性认证。
- README/AGENTS保存字体与字号约定。用户原有暂不推送指令保持，仅本地提交。

## 参考与边界

实际查阅[W3C WCAG 2.2 1.4.4解释](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html)：关注文字放大及内容/功能可用；没有将本项目18px说成该条款强制值。参考[苏格兰政府设计体系](https://designsystem.gov.scot/styles/typography)的正文/小字层级（该体系正文小屏16px、大屏19px，小字14/16px），结合本中文研究长文选择18/17px；没有照搬其Roboto要求或宣称采用完整政府设计体系。检索时GOV.UK页面直接打开返回工具Internal Error，未将其未读取全文作为唯一依据。

未外链字体；字体不等于字形保证，实际浏览器计算的是字体栈，缺少某字体由本机回退。此次屏幕排版/放大和实际浏览器范围见TEST-015与`校验/字体字号浏览器核验.json`。原1189文档、协议/论文/插图原件与算法归属保持。
