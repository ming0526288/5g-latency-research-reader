# 五类分析的图片与安全汇总

这里保存已完成实验的汇总副本，供五类结果页和离线重绘使用。没有启动新实验，没有重新计算原始包时延。原研究报告及失败证据的网页链接保留在五个正文中；完整日志、pcap、UE 凭据和运行二进制没有新增到阅读站。

|文件|来源和用途|
|---|---|
|`共同规则短流汇总.json`|`common-policy-rerun/evidence/short/current_matrix.json` 中 TDD、SCS、多 UE、多 UE × TDD、分层的 73 项；不含另 6 项顺序条件。完整源矩阵的 counts 保留其原有全部分组身份，cases 为上述选取范围|
|`共同规则长流汇总.json`|共同规则尾时延 4 项，每 UE 2 Mbps，内部 OFF，100000 个统计包 / UE；和固定总量长流不是同一批|
|`固定CPU_TDD汇总.json`|24 个最终完整条件，25 次尝试；主表的完整关联/统计分别为 5175000/5112000 包。失败完整应用样本另见原报告，未混入主表|
|`固定负载长流汇总.json`|独立 12 项：短流每 UE 0.5 Mbps，长流总 UL 4 Mbps；统计合计 2704000 包|
|`来源与图片核验.json`|原聚合文件、12 份已读报告、7 张原图及 4 份汇总副本的 SHA；图的批次身份与复制方式|
|`重绘图片核验.json`|6 张重绘图的输入 SHA、条件 ID、指标含义及图片 SHA|

图片在 `说明/五类时延分析/图片/`，生成器复制散列命名的副本到 `网页/images/`。TDD 确认组和固定负载长流共 4 张现用原图，另有 SCS、多 UE、分层的 3 张旧程序历史图；历史图只作版本混用反例。6 张主图从共同规则已完成汇总重新绘制。失败无性能值，不能画成 0；不同 UE 和批次不合池。

源稿和图片已经生成在网页里，Git clone 后可直接阅读，不需访问原实验目录。维护命令从仓库根目录执行：

```bash
python3 tools/update_experiments.py
python3 tools/check_experiments.py
python3 tools/validate_reader.py
```

可选重绘：在装有 Matplotlib 的 Python 环境执行 `python3 tools/draw_experiment_results.py`，再重新生成网页。离线核验只检查保存副本的哈希、数值闭合、页面/锚点和批次身份；不等于重新读取全部原始包或重新完成通信实验。
