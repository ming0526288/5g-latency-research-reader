2026-11-03，CHG-014，仅网页排版，不是通信研究。

## 实际检查

- 读取样式和前轮浏览器图，原正文15px、窄屏14px，导航/卡片13px，来源/辅助10–12px。查阅W3C 1.4.4解释及苏格兰政府设计体系排版全文；来源/选择边界见CHG-014，不宣称全站WCAG达标。
- 运行既有 `tools/check_interactions.cjs`，使用VS Code Server的现代Node，`NODE_PATH=/usr/share/nodejs`：退出0，PASS，无DOM脚本错误。算法选择/知识结果互跳、五类分析、数学/间距、书签、搜索、PDF与协议定位保持。该测试不测字体像素或布局，实际字号另在Firefox核对。
- Firefox无头/Marionette检查实际file入口，按getComputedStyle读取：正文18px、窄屏17px，导航/卡片说明16px，结果标题17px、来源14px、表格16px；字体栈Arial及系统中文回退符合声明。实际标题/表图/导航文字可见，正文、算法选择、QUEST结果、窄屏和菜单预览通过。
- 基准文字偏好模拟：把根字号设为200%，正文实际36px、导航32px，控制区在顶部下方；修正侧栏布局后，1440px视口正文宽度仍≥600px，来源标签占正文整行，无全页横向溢出。这个步骤是根文字偏好的两倍模拟，不等同于真实浏览器全页缩放或完整WCAG审核。
- Firefox外窗请求390px但最小窗口限制使实际内容500×914，按实际记录。另在同源iframe中加载真实阅读站，iframe内容320×1000，算法卡片应用实际320px媒体查询、单列且无全页横向溢出；不是实体手机或VPN测试。
- 选定浅/深主题辅助文字色对按相对亮度公式计算，对比度均≥4.5；数值写入浏览器摘要，不代表全站所有图内文字/控件已完成可访问性测试。图中文字仍为原文件，可用已有放大入口。
- 最终 `python3 tools/validate_reader.py`退出0：1189文档、4算法方向、36 PDF、34协议分册、26 ZIP及已有路由/离线资源保持，无新错误；既有交互检查在最后样式调整后再运行，退出0。Git diff核对catalog、payload及正文无修改。

浏览器脚本最终退出0，共7组检查、8张截图；摘要 `校验/字体字号浏览器核验.json`。截图/辅助脚本只在工作区 `analysis-source-audit/reader-fonts-20261103/`，未提交截图。只回收本轮Firefox。

## 发现与修正

最初浏览器脚本以`.algorithm-card p`读取字号，实际先取到有意使用15px的副标题，两次断言未通过；改为卡片正文选择器后测得16px，重跑通过，不把错误取样当产品字号错误。

首次两倍文字检查技术上无横向溢出，但视觉发现侧栏宽度也按rem翻倍、正文过窄和来源标签竖排。未采纳该布局；将侧栏/目录宽度保持独立布局值、来源整行显示，再重跑实际浏览器，正文可读及宽度检查通过。字体和顶部留白仍随文字偏好放大。

最终diff检查仅排版/维护记录/校验摘要，既有正文、公式payload和原始资料未改。用户暂不推送指令保持。
