# CHG-002 一键打开与后台常驻

2026-11-02。用户要求提供单条命令打开阅读站，随后要求电脑开机期间持续运行，不因关闭终端而停止。

新增`启动阅读站.py`：Python标准库静态服务，仅监听127.0.0.1；普通运行优先8765，匹配已有入口和app.js时复用，否则端口冲突自动后移；通过已安装VS Code Remote CLI真实支持的`code --openExternal`请求本地电脑浏览器打开。没有VS Code时尝试当前桌面浏览器，无法打开则保留地址提示。`--service`固定端口、不复用也不后移，供常驻单元使用。新增Windows批处理直接打开离线HTML，不要求Python。

新增`常驻阅读站.py`：在当前用户的`~/.config/systemd/user/5g-latency-reader.service`写入带本站标记的单元，不覆盖同名无标记服务；使用当前克隆目录生成路径。服务固定8765，Restart=always、RestartSec=3、开机启用；只有明确执行脚本时才配置本机用户服务，普通离线阅读不执行。当前服务器已按用户要求启用linger，因此退出所有登录后用户管理器仍维持，开机可启动。

实际运行配置是用户级服务，没有新增数据库、应用后端、对外监听地址或公开访问。Windows通过现有VS Code/SSH转发访问时，隧道仍需连接；服务器进程不会因断开客户端而停止。电脑休眠或网络中断时不能保证浏览器可达。

依据为本地Remote CLI的openExternal实现、Python标准库和实际systemd状态。工程功能，3GPP/新增数学推导不适用。没有修改研究结论、通信代码或启动无线实验。
